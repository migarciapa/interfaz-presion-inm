ACCEDER AL MODO SERIAL O FRONTAL DEL TWISTORR 74FS AG

ADEVERTENCIA! cada vez que se use [Counters + Measures] se aconseja mantener primero [Measures] y luego [Counters] para no cambiar accidentalmente el modo.

- Asegurese de que el controlador este encendido
- Presione durante dos segundos[Counters + Measures] para acceder al menu principal
- Puede navegar con [Next] para navegar el menu principal
- La primera opcion del menu principal corresponde a modo. En pantalla debe verse "MODE" seguido del modo actual.
- Utilice los botones [Increase] y [Decrease] para cambiar el modo.
- Para salir del menu principal presione [Counters + Measures] y libere rapidamente.
